# Antigravity Hub v0.1.0 Release Notes

**Release Date**: 2026-11-16  
**Type**: Initial Public Hub Release  

---

## 🌟 Highlights & Major Changes

### 1. Official Project Rebranding to "Antigravity Hub"
- Rebranded repository, CLI, and GUI headers from `antigravity-launcher` to **Antigravity Hub**.
- Updated all bilingual localization catalogs (`locales/vi.json` and `locales/en.json`) and application titles.
- Public GitHub repository migration with unified topics and zero-secrets security audit.

### 2. Quota Management & Visual Indicators
- **Dynamic Quota Progress Bar**: Implemented a responsive progress bar in the account table with a dynamic color gradient (vibrant green `#a6e3a1` for healthy quota, shifting through amber `#f9e2af` to red `#f38ba8` when depleted).
- **Quota Reset Countdown**: Real-time timer parsing displaying remaining reset windows (e.g., `Reset in 02:45` or `Reset: HH:MM`).
- **Priority Micro-Steppers**: Added quick reordering steppers (`▲` / `▼`) directly inside the table order cells for manual priority sequencing alongside existing drag-and-drop.

### 3. System Tray & Window Lifecycle Management
- **Background Tray Integration**: Full system tray support with an interactive context menu (Launch App 2.0, Launch IDE, Open Launcher, About, Exit).
- **Hide-on-Launch Prompt**: Added customizable behavior upon launching applications:
  - Prompt dialog with *"Remember my choice"* checkbox.
  - Settings options: *Ask every time*, *Always hide to tray*, *Keep window open*.
- **Close Button Action**: Configurable window close `[X]` action (*Minimize to system tray* vs. *Exit completely*).

### 4. Micro-Proxy Engine & Protocol Conformance
- **Direct Google Connection**: Local micro-proxy (`127.0.0.1:20130`) with dedicated per-account keep-alive socket pools.
- **Dual-Track Subagent Routing**: Fresh account allocation for spawned subagents, preventing single-account quota burnouts (eliminating the 9Router single-account hard-lock flaw).
- **RFC 7230 §3.3.2 / RFC 9112 §6.1 Compliance**: Strips conflicting `Transfer-Encoding` headers when sending explicit `Content-Length`.
- **Hardware-Backed Envelope Encryption**: OAuth tokens encrypted with machine-bound AES-256-GCM and OS Keyring integration.
