# Antigravity Hub v0.1.1 Release Notes

**Release Date**: 2026-11-16  
**Type**: Feature, Performance & Analytics Update  

---

## 🌟 Highlights & Major Changes

### 1. Real-Time Token Analytics & Stream Caching
- **Google Native `usageMetadata` Sniffing**: Sniffs authentic token metrics (`promptTokenCount` -> Sent, `candidatesTokenCount` -> Received, `cachedContentTokenCount` -> Cached) directly from Google's Cloud Code / Gemini Server-Sent Events (SSE) stream chunks with **0ms added latency**.
- **Complete Stream Lifecycle Listening**: Listens across the full SSE stream until stream completion to accurately capture `cachedContentTokenCount` emitted in the final metadata chunk.
- **Independent Storage Architecture (`token_metrics.json`)**: Stored independently at `~/.config/antigravity-launcher/token_metrics.json`. Clearing or pruning `proxy.log` preserves token statistics 100%.
- **Hourly Bucket Aggregation**: Grouped by UTC hour (`YYYY-MM-DDTHH:00:00Z`), maintaining file sizes under 50 KB while auto-pruning buckets older than 31 days once folded into lifetime totals.

### 2. Streamlined Token Metrics Bar
- **3 Compact Metric Cards (48px Height)**:
  - **Sent (Input)**: Blue (`#89b4fa`) card showing total input tokens.
  - **Received (Output)**: Green (`#a6e3a1`) card showing generated candidate tokens.
  - **Cached (Hit)**: Amber (`#f9e2af`) card displaying prompt cache hits.
- **Full 15-Digit Number Formatting**: Displays exact token quantities with comma separators (e.g. `59,609,651`) in bold 13px typography.
- **Redundant Total Card Removed**: Completely eliminated the redundant total card from code and layout to optimize vertical spacing and avoid layout overlaps.
- **Interactive Timeframes**: 1-click toggling between **[24h]**, **[7D]**, **[30D]**, and **[All time]** aggregated views.

### 3. Streamlined Dashboard Activity Table (3 Columns)
- **3-Column Essential View**: Displays `Model | In / Out | When`, rolling up to 50 recent requests.
- **Authentic Model Name Extraction**: Proxy inspects request JSON payloads (`model`, `metadata.model`, `requests[0].model`) and URL paths to extract real model names (`gemini-2.5-pro`, `gemini-2.0-flash`, etc.) logged with `[MODEL: <name>]`.
- **Aligned Typography**: Column headers and data cells strictly aligned (`Model` left, `In / Out` and `When` right) with padding to eliminate cut-off edges.
- **Clean Interface**: Removed legacy `View Full Log` button from Dashboard header to eliminate visual clutter.

### 4. Dedicated Logs View (`LogsView`) on Sidebar
- **Independent Sidebar Navigation**: Dedicated `Logs` / `Nhật ký` page accessible directly from the sidebar.
- **Structured 5-Column Table**: `Thời gian | Luồng | Tác vụ / Model | Tài khoản | Tokens` (removed status column).
- **Zero-Freeze High Performance**: Replaced nested cell widgets with native `QTableWidgetItem` styled with theme colors (`#89b4fa` for MAIN, `#cba6f7` for SUBAGENT, `#a6e3a1` for tokens), rendering 100 rows in < 2ms without UI freezing.
- **100-Log Rolling Fetch**: Fetches the 100 most recent logs for responsive loading.
- **Open Log File Action**: Added **"Mở tệp Log"** (`Open Log File`) toolbar button to open raw `proxy.log` directly in the system text editor.
- **Search & Clipboard**: Real-time keyword filter, instant refresh (`↻`), copy all/selected rows, and log clearing.

### 5. Proxy Real-Time Timestamp Injection
- **Automatic Logger Hook**: Intercepts `console.log`, `console.warn`, and `console.error` in the Node.js Proxy to inject real-time `[HH:MM:SS]` prefixes at source.
- **Eliminated Duplicate Timestamps**: Prevents log parser from falling back to the current wall-clock time when reading older log entries.

### 6. Architectural Quality & Test Coverage
- **Strict 300 LOC Cap**: All source modules remain strictly under 270 LOC (`proxy/index.js` 266 LOC, `launcher_token_widget.py` 151 LOC, `launcher_activity_widget.py` 230 LOC, `launcher_view_logs.py` 238 LOC).
- **100% Automated Test Suite**: 67/67 unit tests passing with full coverage for token storage, timeframe aggregation math, log-clearing independence, UI widgets, 5-column logs table, and model name extraction.
