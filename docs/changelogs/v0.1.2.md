# Antigravity Hub v0.1.2 Release Notes

**Release Date**: 2026-11-16  
**Type**: Reliability, Installation Pipeline, Security & Cross-Platform Polish  

---

## 🌟 Highlights & Major Changes

### 1. Automated Root CA & Dual-Layer Trust Architecture
- **Combined CA Trust Bundle (`ca-bundle.crt`)**: Solved the upstream Golang TLS verification failure (`tls: failed to verify certificate: x509: certificate signed by unknown authority` on `https://oauth2.googleapis.com/token`) by creating a combined certificate bundle pairing Mozilla's public Root CAs (via `certifi`) with the local Antigravity Root CA.
- **Enhanced Subject Alternative Names (SAN)**: Updated `proxy/cert_provider.js` to explicitly register `oauth2.googleapis.com`, `accounts.google.com`, and `cloudaicompanion.googleapis.com` into the leaf certificate's SAN extension, satisfying strict x509 hostname checkers.
- **Cross-Platform OS Trust Store Installation (`launcher_cert.py`)**:
  - **Windows**: Automatically installs Root CA into `Cert:\CurrentUser\Root` using `certutil.exe -addstore -user "Root"` with timeout-guarded safety.
  - **Linux**: Installs into `/usr/local/share/ca-certificates` via `update-ca-certificates` and user NSS database (`~/.pki/nssdb`) for Chrome, VS Code, and Electron runtimes.
- **GUI & CLI Management**: Added `python launcher/main.py --install-cert` and a dedicated **"Cài đặt Chứng chỉ Root CA"** button in Settings view.

### 2. Comprehensive 5-Step Automated Installation Pipeline
- **Unified Pipeline across Windows & Linux**: Standardized `setup.bat`, `setup.sh`, and `install.sh` into an automated, fail-safe 5-step sequence:
  1. **Python Dependencies**: Installs PyQt6, requests, cryptography, and keyring.
  2. **Micro-Proxy Dependencies**: Installs `node-forge` via `npm install` inside `proxy/`.
  3. **Root CA & Trust Bundle**: Generates local certificates and installs into OS trust store (`--install-cert`).
  4. **9Router Automated Migration**: Detects and imports accounts from 9router SQLite (`--import-9router`).
  5. **Desktop Shortcut & Symlinks**: Creates desktop shortcuts and shell symlinks (`--create-shortcut`).

### 3. Native 9Router Migration Engine (`launcher_importer.py`)
- **Direct Database Extraction**: Connects directly to 9router's SQLite database (`%APPDATA%\9router\db\data.sqlite` on Windows or `~/.config/9router/db/data.sqlite` on Linux).
- **Zero-Loss Credential Conversion**: Extracts access tokens, refresh tokens, project IDs, priorities, and active states, automatically encrypting them with local AES-256-GCM envelope encryption into `accounts.json` and `profiles.json`.
- **Standalone CLI Command**: Accessible on demand via `python launcher/main.py --import-9router`.

### 4. Zero-Freeze Windows UX & Headless Proxy Optimization
- **Suppressed Console Windows**: Added `CREATE_NO_WINDOW (0x08000000)` flag on Windows for all background Node.js and proxy processes, eliminating intrusive black console popup windows.
- **Eliminated PowerShell Startup Lag**: Replaced slow PowerShell port cleanup with instant native `netstat` and `taskkill` parsing (< 15ms vs 2.5s).
- **Non-Blocking GUI Event Pump**: Integrated `QApplication.processEvents()` during socket polling in `ensure_proxy_running()` and OAuth initialization, keeping the PyQt6 event loop responsive at 60 FPS.
- **Detached Application Spawning**: Applied `DETACHED_PROCESS` when launching Antigravity App or IDE to decouple child processes from the launcher parent.

### 5. Streamlined OAuth & Silent Auto-Closing Tab
- **Immediate Silent Tab Closure**: Enhanced `proxy/oauth_handler.js` to execute inline JavaScript `window.open('', '_self', ''); window.close();` across multiple DOM lifecycle events (`DOMContentLoaded`, `load`, and staggered timeouts) upon successful Google OAuth callback.
- **Zero-Banner Clean State**: Removed all static success banners and text paragraphs. On successful authentication, the tab remains completely silent and blank before terminating instantly.
- **Removed Manual URL Fallback**: Completely removed the redundant fallback URL input (`QLineEdit`) and manual submit button from `launcher_oauth.py`, simplifying the "Add Account" dialog to a clean, focused modal.

### 6. Master Key Cross-Runtime Parity
- **Keyring & Node Synchronization**: Hardened `launcher_crypto.py` to synchronize Windows Keyring master keys to `.master_key` fallback, guaranteeing 100% AES-256-GCM token decryption compatibility between Python and Node.js.

### 7. Test Suite Expansion & Quality Assurance
- **Full Test Coverage (78 Tests Passing)**: Introduced `test_cert.py` and expanded test suites covering certificate generation, SAN verification, cross-runtime parity, and remediation logic. All 78 tests pass in 8.47 seconds.
