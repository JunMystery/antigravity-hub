# Antigravity Hub v0.1.3 Release Notes

**Release Date**: 2026-11-18  
**Type**: Feature Release, Cross-System Data Portability, Plain-JSON Storage & Settings GUI Fix  

---

## 🌟 Highlights & Major Changes

### 1. Universal Plain-JSON Backup & Restore Engine (`launcher_backup.py`)
- **Self-Contained Portable Archive (v2.0)**: Backs up all registered accounts (`accounts.json` in plain JSON) and user profiles (`profiles.json`) into a compressed `.zip` archive containing a `backup_manifest.json` (`token_format: "plain"`), ensuring exported accounts remain immediately usable when restored on a new machine or different OS.
- **Cross-OS & Cross-User Path Remapping**: Automatically remaps foreign `data_dir` entries (e.g., Linux `/home/...` restored on Windows or vice versa) to the target system's `PROFILES_BASE_DIR` and preserves valid local `app_binary` / `ide_binary` paths when backed-up paths do not exist locally.
- **Legacy Encrypted Backup Guard**: Detects legacy machine-encrypted `enc:v1:` / `enc:v2:` tokens during restore and returns a clear bilingual diagnostic error instead of silently importing unusable credentials.
- **Dual Restoration Modes**:
  - **`replace` (Default)**: Overwrites current local credentials and launcher profiles with the archive contents, ensuring clean environment migration across machines.
  - **`merge`**: Performs non-destructive deduplication. Existing accounts and profiles with matching emails or IDs are preserved, while novel accounts are appended with sequential order indexing (`order = len + 1`).
- **Immediate Proxy Reload (`cmd=reload`)**: Added a `reload` control command in `proxy/account_rotator.js` that clears stale `unhealthyUntil` cooldowns and reloads `accounts.json` / `profiles.json` immediately after restore.
- **CLI Management**:
  - `python3 launcher/main.py --backup [optional_output_path]`
  - `python3 launcher/main.py --restore <backup_file.zip> [--restore-mode replace|merge]`
- **Native GUI Settings Integration (`BackupSettingsGroup`)**:
  - Added dedicated "Sao lưu & Phục hồi" card in Settings View with Replace/Merge modal prompt, live account/quota refresh, and immediate Micro-Proxy reload.

### 2. Removal of Machine-Bound Token Encryption & Keyring
- **Plain-JSON Storage Everywhere**: Removed `launcher/launcher_crypto.py`, `launcher/launcher_keyring.py`, `proxy/crypto_helper.js`, `tests/test_crypto.py`, and the `keyring` dependency from `requirements.txt` so accounts stored locally and exported in backups are never locked to a single machine's keyring or hardware fingerprint.
- **Direct Token Handling**: Simplified `launcher_storage.py`, `launcher_proxy.py`, `proxy/oauth_flow.js`, `proxy/token_manager.js`, and `proxy/chat_handler.js` to read and write plain OAuth tokens directly (preserving `0600` file permissions on Unix).

### 3. Complete Decommission of Legacy 9Router Importer
- **Removed `launcher_importer.py` (142 LOC)**: Eliminated external SQLite scraping of 9router databases (`data.sqlite`).
- **Streamlined Setup Pipelines**:
  - `install.sh`: Reduced to a 5-step clean pipeline (`PyQt6`, `requests`, `cryptography`).
  - `setup.sh`: Reduced to a 4-step clean pipeline.
  - `setup.bat`: Reduced to a 4-step clean pipeline.
- **CLI Clean-up**: Removed obsolete `--import-9router` argument and associated localization keys.

### 4. Settings View GUI Fix (`Application Paths` Row Height & Scroll Layout)
- **Vertical `QScrollArea` Layout**: Wrapped Settings sections in a borderless vertical `QScrollArea` (`setWidgetResizable(True)`) with the `Save` button pinned cleanly at the bottom, preventing vertical widget compression when window height is 480–620px.
- **Minimum Row Height & QSS Polish**: Enforced `32px` minimum height and fixed vertical size policy on `Application Paths` inputs and `Browse...` / `Auto-Detect` buttons (in both `SettingsView` and `LauncherSettingsDialog`), and added Catppuccin Mocha QSS styling for `QLineEdit`, `QScrollArea`, and `QGroupBox::title` in `launcher_theme.py`.
- **Localization Polish**: Added bilingual translation keys (`en.json`, `vi.json`) for backup/restore prompts, legacy encryption errors, and `btn_install_cert` retranslation; updated sidebar footer version indicator to `v0.1.3 • JunMystery`.

### 5. Upstream Timeout & Proactive Failover Optimization
- **42s Preemptive TTFB Failover**: Reduced Time-To-First-Byte timeout from 120s to 42s in `proxy/chat_handler.js`, allowing the proxy to detect sluggish upstream thinking models (such as `gemini-3.8-flash-high`) and proactively failover to healthy accounts before the IDE client's hard 60s abort trigger.
- **Cooldown on Socket Timeout**: Automatically assigns a 60-second cooldown (`unhealthyUntil`) to accounts experiencing upstream socket hang-ups.
- **Accurate Log Categorization**: Separated early client cancellations (`[CLIENT-CLOSED]`) from true upstream errors, preventing misleading network failure alerts in logs.
- **Keep-Alive Socket Hygiene**: Tuned `agent_pool.js` with `maxFreeSockets: 5` and `keepAliveMsecs: 10000` to prevent socket reuse of silently closed connections.

### 6. Test Suite & Verification
- Expanded `tests/test_backup.py` with comprehensive test cases:
  - Plain-JSON archive generation and v2.0 manifest validation.
  - Full restore in `replace` and `merge` modes.
  - Cross-OS `data_dir` and invalid binary path remapping.
  - Rejection of legacy machine-encrypted `enc:v1:`/`enc:v2:` archives and invalid zips.
- Expanded `tests/test_view_navigation.py` with `test_settings_application_paths_row_height_not_squished` verifying `QScrollArea` and `>= 32px` row heights at minimum window size (`760x480`).
- Expanded `tests/test_proxy_rotation.py` with `test_timeout_failover_cooldown_and_skip` verifying automatic cooldown assignment and rotation progression under socket timeout.
