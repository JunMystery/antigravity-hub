# Antigravity Hub v0.1.4 Release Notes

**Release Date**: 2026-11-18  
**Type**: Bugfix Release & Concurrent Streaming Hardening  

---

## Highlights & Major Changes

### 1. Concurrent Agent Stream Hang Remediation (`proxy/chat_handler.js`)
- **Fixed Orphaned `clientRes` on Post-200 Inactivity Timeout**: Previously, when an upstream response had already sent `200 OK` headers and later hit `INACTIVITY_TIMEOUT_MS`, destroying `activeGRes` before `gReq.destroy()` prevented `gReq.on("error")` from firing, leaving `clientRes` open indefinitely with zero output while the client waited forever. Added `terminateClient(reason)` to immediately tear down `clientRes` cleanly on post-header timeout.
- **Extended Thinking Inactivity Window (120s)**: Raised `INACTIVITY_TIMEOUT_MS` from `45s` to `120s` to accommodate heavy thinking models (such as `gemini-3.8-flash-high` on >300K token contexts) while keeping `TTFB_TIMEOUT_MS` at `42s` for preemptive pre-header failover.
- **Premature Upstream Close Handling**: Handled upstream `close` without `end` (`!gRes.complete`) in both `proxy/chat_handler.js` and `proxy/index.js` (non-chat pass-through) by terminating the client stream instead of hanging open.
- **Failover Listener Cleanup**: Updated `attachClientCloseHandler` in `proxy/socket_cleanup.js` to return a `detach()` function invoked in `safeEndSession()`, eliminating duplicate `close` listener accumulation on `clientRes` across failover retries.
- **Top-Level Async Error Safety**: Wrapped `executeGoogleChatRequest` and all retry `.then()` chains with `try/catch` and `.catch()` guards so unexpected rejections never orphan a client response.

### 2. Proxy Transport & Token Refresh Hardening
- **`readErrorBody` Close & Timeout Guard (`proxy/chat_payload_helper.js`)**: Hardened `readErrorBody(res, timeoutMs = 5000)` to resolve immediately on `close` or `readableEnded` and destroy stalled error sockets after `5s` with `timer.unref()`.
- **OAuth Refresh Fetch Timeout (`proxy/token_manager.js`)**: Added `AbortSignal.timeout(15000)` to `fetch("https://oauth2.googleapis.com/token")` so a stalled refresh cannot block concurrent agents sharing `refreshPromises`.
- **`CONNECT` Head Buffer & Long SSE Streams (`proxy/index.js`)**: Added `clientSocket.unshift(head)` before emitting `connection` to `internalHttpsServer` for pipelined TLS ClientHello bytes, set `internalHttpsServer.requestTimeout = 0` to avoid Node's 5-minute default cutoff on long agent turns, and added `req.on("error")` handling.

### 3. Version Bump & Verification
- Bumped package and UI versions to `v0.1.4` (`launcher/__init__.py`, `launcher/launcher_sidebar.py`, `proxy/package.json`, `proxy/package-lock.json`).
- Added `tests/test_proxy_hang_remediation.py` covering post-200 inactivity timeout teardown, premature upstream `close`, `readErrorBody` on `close`, and failover listener cleanup (19/19 proxy tests passing).
