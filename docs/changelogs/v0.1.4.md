# Antigravity Hub v0.1.4 Release Notes

**Release Date**: 2026-11-18  
**Type**: Bugfix Release, Concurrent Streaming & Timeout/Abort-Loop Hardening  

---

## Highlights & Major Changes

### 1. Budget-Aware TTFB Failover & Timeout/Abort-Loop Remediation (`proxy/chat_handler.js`, `proxy/chat_payload_helper.js`, `proxy/agent_pool.js`)
- **Budget-Aware Preemptive TTFB (`25s -> 22s -> remaining`)**: Replaced the fixed `42s` TTFB cutoff (which left only `18s` before the IDE's `60s` hard timeout and caused cascading `[UPSTREAM-ERR]` -> `[CLIENT-ABORT]` loops on heavy 330K–460K token contexts) with `computeTtfbTimeoutMs` / `hasFailoverBudget` inside a `58s` client budget (`25s` on attempt 1, `22s` on attempt 2, remaining budget on attempt 3; skips doomed failovers when `< 10s` remain).
- **Pre-Header Abort Rotation**: When the client IDE aborts before headers arrive (`!clientRes.headersSent`) on a failover attempt (`attempt > 1`) or after waiting `>= 15s`, the proxy now purges that account's socket pool and advances `nextAccount()` so the IDE's immediate retry uses a fresh account instead of looping on the same stalled slot.
- **Socket Pool Hygiene & Hop-by-Hop Header Stripping**:
  - Added `buildForwardHeaders` in `proxy/chat_payload_helper.js` to strip hop-by-hop headers (`connection`, `proxy-connection`, `keep-alive`, `transfer-encoding`, `expect`).
  - Purged account agent pools via `agentPool.destroyAgentForAccount(account)` on timeout, socket error, or pre-header abort.
  - Updated `proxy/agent_pool.js` (`maxFreeSockets: 2`, `keepAliveMsecs: 5000`, `scheduling: "lifo"`, and automatic `15s` idle free-socket eviction while retaining `timeout: 120000` for active streams) to eliminate stale half-open sockets against Google Frontend.
- **Slow TTFB Diagnostics**: Added `[SLOW-TTFB]` logging when upstream headers take `>= 10s`, plus total elapsed time and attempt count on `[UPSTREAM-TIMEOUT]`.

### 2. Concurrent Agent Stream Hang Remediation (`proxy/chat_handler.js`, `proxy/socket_cleanup.js`, `proxy/index.js`)
- **Fixed Orphaned `clientRes` on Post-200 Inactivity Timeout**: Added `terminateClient(reason)` to tear down `clientRes` cleanly when `INACTIVITY_TIMEOUT_MS` fires after `200 OK` headers were already sent, preventing clients from waiting indefinitely with zero output.
- **Extended Thinking Inactivity Window (120s)**: Raised `INACTIVITY_TIMEOUT_MS` from `45s` to `120s` for heavy thinking models on >300K token contexts.
- **Premature Upstream Close Handling**: Terminated client streams when upstream closes without `end` (`!gRes.complete`) in both `proxy/chat_handler.js` and `proxy/index.js` (non-chat pass-through).
- **Failover Listener Cleanup & Async Guards**: Updated `attachClientCloseHandler` to return a `detach()` function invoked in `safeEndSession()` and wrapped `executeGoogleChatRequest` and retry chains with `try/catch` and `.catch()`.
- **Transport Hardening**: Hardened `readErrorBody(res, timeoutMs = 5000)` to settle on `close`/`readableEnded`/`timeout` with `res.destroy()` and `timer.unref()`, added `AbortSignal.timeout(15000)` to OAuth refresh `fetch()`, unshifted pipelined `head` buffers on `CONNECT`, and set `internalHttpsServer.requestTimeout = 0`.

### 3. Launcher Startup Fix (`launcher/launcher_window.py`)
- Removed the 600ms startup auto-redirect to Settings so the launcher always opens cleanly on Dashboard.

### 4. Version Bump & Verification
- Bumped package and UI versions to `v0.1.4` (`launcher/__init__.py`, `launcher/launcher_sidebar.py`, `proxy/package.json`, `proxy/package-lock.json`).
- Added `tests/test_proxy_hang_remediation.py` covering post-200 inactivity teardown, premature upstream `close`, `readErrorBody` on `close`, failover listener cleanup, `25s -> 22s -> 11s` TTFB budget, hop-by-hop header stripping, and pre-header abort rotation/pool purge (21/21 proxy tests passing).
