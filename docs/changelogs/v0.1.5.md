# Antigravity Hub v0.1.5 Release Notes

**Release Date**: 2026-11-19  
**Type**: Feature Release & UI/Quota Enhancements

---

## Highlights & Major Changes

### 1. Round Robin Toggle & Fixed Account Mode
- **Accounts Tab Rotation Toggle**: Added an on/off toggle switch in the **Accounts** tab to disable or re-enable automatic account rotation at any time without stopping the local proxy.
- **Two-Way Dashboard Synchronization**: Turning rotation on or off in the **Accounts** tab stays synchronized with the **Pause / Resume** control on the **Dashboard**, locks/unlocks the `Req / acc` threshold automatically, and persists across restarts.
- **Pinned Session Continuity**: When rotation is paused, requests stay pinned to the selected account so long conversations and cached context remain intact.

### 2. Direct Active Account Switcher & OAuth Account Chooser
- **Dashboard Quick Selector**: Added an **Active Account** dropdown directly on the **Dashboard** to switch to any account in one click instead of stepping through `Next`.
- **Accounts Tab Quick Action & Highlight**: Added a **Use Account** button in the **Accounts** tab, automatically highlighted and selected the active account row (`●`), and synchronized profile selection when launching the App or IDE.
- **Account Chooser on Login**: Adding or re-linking a Google account now prompts the Google account chooser so you can pick the exact account to sign in with.

### 3. Separate Argon (Weekly) Quota Tracking
- **Accurate Weekly Separation**: Fixed an issue where Argon weekly limits overwrote the standard Gemini weekly percentage.
- **Dedicated Argon (Weekly) Column**: Added an **Argon (Weekly)** column with its own progress bar and reset countdown in the **Accounts** tab, as well as CLI `--list` and `--refresh-quota` output.

### 4. Dashboard Status & Layout Stability
- **Clean Request Counter in Fixed Mode**: When automatic rotation is turned off, the **Turn** indicator displays the single request count cleanly (instead of `N/M`) under a `Requests` label.
- **Anti-Jitter UI Stability**: Preserved the paused state accurately during active requests and stabilized status column and button widths so controls no longer shift horizontally when traffic starts or stops.
