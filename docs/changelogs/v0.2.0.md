# Antigravity Hub v0.2.0 Release Notes

**Release Date**: 2026-11-25  
**Type**: Feature Release, Advanced Model Routing & Data Persistence Hardening

---

## Highlights & Major Changes

### 1. Dashboard Inline Account Pinning & Strict Failover Lock (`launcher/launcher_widget.py`, `launcher/launcher_view_dashboard.py`, `proxy/account_rotator.js`, `proxy/chat_handler.js`, `proxy/rotator_persistence.js`)
- **Inline Account Selector**: Replaced static paused status text in `CompactStatusBar` (`combo_account`) with an interactive selector supporting `Auto (Round Robin)` (`AUTO`) or continuous pinning to any configured account (including `[Deactive]` accounts without re-enabling them in Round Robin).
- **Proxy Pin & Persistence**: Wired `on_pin_account_selected` in `launcher/launcher_window.py` to issue `pin_account` / `unpin_account` commands and persisted active pin state across proxy restarts via `rotator_state.json`.
- **Strict Failover Lock**: Updated `AccountRotator.allocateAccountForRequest` and `proxy/chat_handler.js` so locked requests (`isAccountLocked`) skip 429/403/404/network account failover and perform at most 1 OAuth token refresh attempt on 401 before returning 503 Auth Shield.

### 2. Dedicated Model Rules & Advanced Multi-Model / Multi-Account Routing (`launcher/launcher_view_model_rules.py`, `launcher/launcher_model_rule_editor.py`, `launcher/launcher_model_selector.py`, `launcher/launcher_model_discovery.py`, `proxy/model_rule_engine.js`, `proxy/rotator_state_loader.js`, `proxy/account_rotator.js`, `proxy/account_routing.js`)
- **Dedicated Sidebar View**: Separated Model Rules from the Dashboard into its own `ModelRulesView` (`nav.model_rules`), removing `btn_model_rules` from `DashboardView` and retiring `launcher/launcher_model_rules_dialog.py`. Configured `44px` table row heights with `NoEditTriggers` / `NoFocus` to eliminate text clipping and accidental inline edit boxes, summarized multi-model and multi-account columns with full-list tooltips, and shared per-account scan cache (`_scan_cache`) with the rule editor.
- **Account-Scoped Multi-Model & Multi-Account Rule Editor (`ModelRuleEditorDialog`, `MultiModelSelector`)**: Ordered target accounts above the model list so models stay hidden until at least one account is selected, then dynamically display the union of supported models for the selected accounts (auto-querying uncached accounts in the background). Added live keyword search (`edit_search` using `setHidden`) and a **Query Model** button (`fetch_all_accounts_models`) that preserve all checked selections across filtering and re-querying (`_checked_map`), unsupported-account warning badges (`[! missing/total]`) with detailed unsupported/supported email tooltips, quick account selection controls (`All`, `Active`, `None`), `priority` failover vs `round_robin` pool selection (`ruleCursors`), and per-rule `fallback_to_global` toggle.
- **Multi-Pattern Routing Engine**: Implemented `getRulePatterns`, `doesPatternMatch` (OR evaluation across `patterns` using `contains`, `exact`, or fault-tolerant `regex`), `resolveRulePool`, `allocateForModelRule`, `pickNextRuleAccount`, and `buildRequestContext` in `proxy/model_rule_engine.js`, with backward-compatible normalization (`normalizeRulePatterns`, `sanitizeModelRules`) in `proxy/rotator_state_loader.js` and updated `matchedRule` / `model_routed` reporting in `proxy/account_rotator.js`.
- **Model Discovery, Scan-to-Rule & Live Route Tester**: Added parallel account model fetching (`fetch_all_accounts_models`, `fetch_account_models`), activity log model extraction (`discover_models_from_logs`), one-click scan-to-rule creation (pre-selecting the scanned account and prioritizing its models), and a local route simulator (`simulate_model_route`) in `launcher/launcher_model_discovery.py`, with full `en.json`/`vi.json` localization parity (236 keys).

### 3. Atomic Data Persistence & Update-Safe Setup (`launcher/launcher_storage.py`, `launcher/launcher_paths.py`, `launcher/launcher_cert.py`, `proxy/oauth_flow.js`, `proxy/index.js`, `setup.bat`, `setup.sh`, `install.sh`)
- **Atomic JSON Writes & Recovery**: Hardened `_secure_write` and `_read_json_with_backup` in `launcher/launcher_storage.py` using `.tmp` staging, `os.fsync`, atomic `os.replace`, `.bak` preservation, automatic `.bak` recovery, and `.corrupt.<ts>` backup on parse failure. Added `writeJsonAtomic` with `.bak` preservation in `proxy/oauth_flow.js` (`saveAuthorizedAccount`).
- **Persistent Root CA Storage**: Moved generated TLS certificates (`ca.crt`, `ca.key`, `ca-bundle.crt`) from the repository directory (`proxy/certs/`) to `CONFIG_DIR/certs/` (`launcher/launcher_paths.py`, `launcher/launcher_cert.py`, `proxy/index.js`, `proxy/cert_provider.js`) with automatic one-time migration (`migrateLegacyCerts` / `ensure_certificates`), ensuring launcher settings, logs, and Root CA survive repository updates or replacements.
- **Update-Safe Setup Scripts**: Added a `--stop-proxy` pre-step in `setup.bat`, `setup.sh`, and `install.sh` to shut down any background Micro-Proxy instance before installing dependencies or updating certificates/shortcuts.

### 4. Version Bump & Verification
- Bumped package and UI versions to `v0.2.0` (`launcher/__init__.py`, `launcher/launcher_sidebar.py`, `launcher/launcher_prompt_dialog.py`, `proxy/package.json`, `proxy/package-lock.json`).
- Added unit tests in `tests/test_account_pinning_and_routing.py`, `tests/test_advanced_model_rules.py`, and `tests/test_data_persistence_and_setup.py`.
