# Antigravity Hub v0.2.1 Release Notes

**Release Date**: 2026-11-26  
**Type**: Patch Release, Round Robin Unification & Audit Hardening

---

## Highlights & Major Changes

### 1. Per-Rule Round Robin Threshold, Persistence & Failover (`proxy/model_rule_engine.js`, `proxy/rotator_state_loader.js`, `proxy/rotator_persistence.js`, `proxy/account_rotator.js`)
- **Configurable `requests_per_account` per Rule**: Added `requests_per_account` normalization in `sanitizeModelRules` (`0` inherits global `requests_per_account`; `>= 1` overrides per rule) without incrementing global `currentAccRequestsServed` or advancing global `accountIndex`.
- **State Persistence (`rule_states`)**: Added `serializeRuleStates` and `restoreRuleStates` in `proxy/rotator_persistence.js` to persist each rule's `account_index`, `current_req_served`, and last account identity into `rotator_state.json`, automatically pruning removed rules (including when all rules are deleted).
- **Cyclic Intra-Rule Failover & Cursor Sync**: Updated `pickNextRuleAccount` and `buildRequestContext` so failed Round Robin rule requests retry from the next healthy account in cyclic pool order (instead of restarting at index `0`) and persist the updated cursor.
- **Threshold-Lowering Guard & Pause/Pin Precedence**: Added a mid-cycle guard when lowering `requests_per_account` below previously served count (`baseServed >= effectiveThreshold` advances cleanly instead of overflowing `servedCount`), while keeping Model Rules higher priority than Dashboard Pause/Pin (Pause/Pin applies to unmatched traffic and `fallback_to_global`).

### 2. Model Rules UI, Dashboard Turn Display & Modular Split (`launcher/launcher_rule_account_picker.py`, `launcher/launcher_model_rule_editor.py`, `launcher/launcher_model_rule_formatter.py`, `launcher/launcher_view_model_rules.py`, `launcher/launcher_view_dashboard.py`, `proxy/account_routing.js`, `proxy/index.js`, `launcher/locales/en.json`, `launcher/locales/vi.json`)
- **Per-Rule Threshold Control & Formatting**: Extracted `RuleAccountPicker` (`launcher/launcher_rule_account_picker.py`) and cell formatters (`launcher/launcher_model_rule_formatter.py`) so all modules stay under 300 LOC, added a conditional `Req / account` spinbox (`Inherit global` at `0`) for `round_robin` rules in `ModelRuleEditorDialog`, and displayed effective thresholds (`4 req` or global-inherited) in the Model Rules table.
- **Accurate Dashboard Status & Turn Indicator**: Propagated rule `requests_per_account`, `current_req`, and `model_rule_strategy` through `proxy/index.js`, `proxy/account_routing.js`, and `DashboardView` (`X/Y` for Round Robin rules, `—` / Priority for Priority rules, and `∞` for non-rule pinned traffic), with 5 new synchronized keys in `en.json` and `vi.json`.

### 3. Version Bump & Verification
- Bumped application, UI footer, and proxy package versions from `v0.2.0` to `v0.2.1` (`launcher/__init__.py`, `launcher/launcher_prompt_dialog.py`, `launcher/launcher_sidebar.py`, `proxy/package.json`, `proxy/package-lock.json`, `README.md`).
- Added automated unit and offscreen Qt UI tests in `tests/test_model_rule_round_robin.py`.
