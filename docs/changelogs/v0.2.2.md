# Antigravity Hub v0.2.2 Release Notes

**Release Date**: 2026-11-26  
**Type**: Patch Release, Window Geometry Persistence, Dashboard / Sidebar & Model Rules UI Polish

---

## Highlights & Major Changes

### 1. Window Geometry, Data-Loss Guard & State Preservation (`launcher/launcher_window_state.py`, `launcher/launcher_storage.py`, `launcher/launcher_window.py`, `launcher/launcher_tray.py`)
- **Fixed Size & Maximize Reset on Tray Restore**: Replaced unconditional `showNormal()` in `LauncherWindow.activate_window()` with `restore_window_from_tray()`, preserving window geometry and maximized state across minimize-to-tray and restore cycles.
- **Persistent Window State Across Restarts & Safe Storage Hardening**: Added targeted `update_settings_fields()` persistence for `window_geometry` and `window_maximized`, guarded `save_data()` and `.bak` rotation against accidental partial/empty profile overwrites, added automatic profile recovery from `accounts.json` when `profiles.json` has an empty `profiles` list, and isolated UI tests from the live user data directory.
- **Reliable OAuth Browser Tab Auto-Close**: Updated `proxy/oauth_handler.js`, `launcher/launcher_oauth.py`, and added `launcher/launcher_browser_close.py` so successful OAuth callback tabs carry an `Antigravity Hub` success title, trigger safe foreground-verified `Ctrl+W` tab closing on Windows, hide the blocked close button after `1.2s` if a browser disallows script close, and restore focus to Antigravity Hub.

### 2. Compact Sidebar & Dashboard Layout (`launcher/launcher_sidebar.py`, `launcher/launcher_paths.py`, `launcher/launcher_theme.py`, `launcher/launcher_widget.py`, `launcher/launcher_view_dashboard.py`)
- **Sidebar Brand Lockup & Quick Launch Buttons**: Replaced the text/icon sidebar header with `Google-Antigravity-Lockup-Full-Color.png` framed in a dark rounded box with a subtle light border (`#6c7086`), tightened vertical spacing, and moved `Launch App (2.0)` and `Launch IDE` directly under the header as compact icon + short-label buttons (`App` / `IDE` with `18x18` `Antigravity.png` and `Antigravity-IDE.png` icons), keeping short labels fixed while updating tooltips on launch.
- **Highlighted Proxied Account & Relocated Selector**: Compacted `CompactStatusBar` to `60px`, restored prominent display of the active proxied account email in the center column (status-colored with width overflow guard and hover tooltip), and relocated the `Auto / Account` selector below the status bar alongside compact `Next` and `Pause` buttons.

### 3. Model Rules UI Polish & A-Z Auto-Sorting (`launcher/launcher_item_list_dialog.py`, `launcher/launcher_model_rule_formatter.py`, `launcher/launcher_view_model_rules.py`, `launcher/launcher_model_discovery.py`, `launcher/launcher_model_selector.py`, `launcher/locales/en.json`, `launcher/locales/vi.json`)
- **`ToggleSwitch` Activation, 5-Column Compact Table & Context Menu**: Replaced the rules table `On` checkbox with `ToggleSwitch` matching the Accounts view, streamlined `tbl_rules` to 5 columns (`Priority`, `On`, `Model Pattern`, `Strategy`, `Target Accounts`) with a right-click row context menu for `Edit` and `Delete`, shortened strategy labels (`RR (Global)`, `RR (N req)`, `Priority`), showed Match Type in hover tooltips and detail headers, and converted verbose `Model Pattern`, `Target Accounts`, and `Available Models` cells into compact clickable summary buttons (`Rule Name (N models)`, `N accounts · Fallback`, `N models`).
- **Shared Searchable Detail Dialog**: Added `ItemListDetailDialog` with quick filtering for inspecting full pattern lists, available models per account, and ordered target accounts (`Active` / `Deactive` preserved in priority order), plus dynamic retranslation of scanned model rows on language switches.
- **Case-Insensitive A-Z Model Sorting**: Sorted discovered, cached, quick-tester, detail-dialog, and rule-editor models alphabetically (A-Z, case-insensitive) while keeping checkbox order stable when toggling items.

- Bumped application, UI footer, and proxy versions from `v0.2.1` to `v0.2.2` (`launcher/__init__.py`, `launcher/launcher_prompt_dialog.py`, `launcher/launcher_sidebar.py`, `proxy/package.json`, `proxy/package-lock.json`, `README.md`).
- Excluded `.playwright/` and `.playwright-mcp/` directories in `.gitignore`.
- Added and updated regression and live-data-isolation tests in `tests/test_data_persistence_and_setup.py`, `tests/test_tray.py`, `tests/test_view_navigation.py`, `tests/test_activity_logs.py`, `tests/test_account_pinning_and_routing.py`, `tests/test_advanced_model_rules.py`, `tests/test_model_rule_round_robin.py`, `tests/test_model_rule_detail_view.py`, and `tests/test_token_stats.py`.
