# Antigravity Hub v0.2.3 Release Notes

**Release Date**: 2026-11-27  
**Type**: Patch Release, Full Theme Support (System / Dark / Light), Comprehensive GUI Theme Audit & Model Rules Priority UX

---

## Highlights & Major Changes

### 1. Full System / Dark / Light Theme & Comprehensive GUI Theme Audit (`launcher/launcher_theme_qss.py`, `launcher/launcher_theme.py`, all GUI views & dialogs)
- **Catppuccin Mocha (Dark) & Catppuccin Latte (Light) Theme System**: Centralized all QSS rules into `launcher/launcher_theme_qss.py` with `DARK_PALETTE`, `LIGHT_PALETTE`, and `build_qss(p)`, alongside `detect_system_theme()`, `resolve_theme()`, and `bind_system_theme_listener()` for live OS `System` / `Dark` / `Light` switching persisted to `settings.theme`.
- **Global `QPalette`, DWM Titlebar Sync & Dynamic Subcontrol Styling**: Added `build_qt_palette()` applied via `QApplication.setPalette()`, `_TitlebarThemeFilter` to automatically sync Windows Dark/Light titlebars (`DwmSetWindowAttribute`) across the main window and every `QDialog`/`QMessageBox`, and semantic QSS rules (`btn_danger:hover`, `btn_auto[auto_state="on"|"off"]`, horizontal `QFrame` dividers, `QMenu::separator`, and disabled input controls).
- **Live Theme Refresh Across All Surfaces & Legacy Modules**: Added `set_semantic_text()` / `refresh_semantic_label()` so status banners (`lbl_info`, OAuth prompts, `SettingsView`, `BackupSettingsGroup`, `LauncherSettingsDialog`) update colors live on theme changes without clobbering plain text, and migrated every widget, custom delegate/painter (`TokenInOutDelegate`, `QuotaCellWidget`, `QuotaProgressBar`, `ToggleSwitch`, `BadgeLabel`, `MetricCard`, `ActivityLogsPanel`, `TokenMetricsBar`, `LogsView`, `get_quota_color`, `get_quota_pill_pixmap`, `launcher_monitor.py`) off hardcoded Mocha hexes.

### 2. Borderless Adaptive Sidebar Header Lockup (`launcher/launcher_sidebar.py`, `launcher/launcher_paths.py`, `launcher/assets/`)
- **Borderless Header Lockup**: Removed the rounded border and dark background frame around `logo_lockup` in the Sidebar header.
- **Dark / Light Asset Swapping & Sidebar Theme Selector**: Replaced the legacy single lockup image with `Google-Antigravity-Lockup-Full-Color-Dark.png` and `Google-Antigravity-Lockup-Full-Color-Light.png`, swapping dynamically inside `SidebarNav.update_theme()`, and placed the Theme selector (`System` / `Dark` / `Light`) above the Language selector at the bottom of the Sidebar.

### 3. Model Rules Layout, Right-Click Menu & Quick Priority Ordering (`launcher/launcher_view_model_rules.py`, `launcher/launcher_rule_account_picker.py`, `launcher/launcher_item_list_dialog.py`)
- **Fixed Column Clipping**: Widened `Model Rules` Priority column to `72px` and Toggle `On` column to `56px` so `OrderCellWidget` and `ToggleSwitch` render without right-edge clipping.
- **Reliable Row Right-Click Context Menu**: Added recursive `bind_row_context_menu()` across `OrderCellWidget`, `ToggleSwitch`, and detail buttons alongside the `viewport()` handler for text cells so right-clicking anywhere on a rule row opens the `Edit` / `Delete` context menu.
- **Unified Quick Priority Ordering Across All Three Surfaces**: Added numeric priority entry + vertical micro-steppers (`OrderCellWidget`) to:
  1. Main **Model Rules** table (`reorder_rule_to()` / `move_rule()` with immediate save & proxy reload).
  2. Target accounts table inside **ModelRuleEditorDialog** (`RuleAccountPicker` with Checkbox + Account columns preserving deactive visibility and checkbox selection).
  3. **RuleAccountsPriorityDialog** popup opened from the `Target Accounts` summary cell, auto-persisting account priority changes and reloading the proxy live.

### 4. Version Bump & Verification
- Bumped application, UI footer, fallback dialog, proxy package, and README versions from `v0.2.2` to `v0.2.3` (`launcher/__init__.py`, `launcher/launcher_sidebar.py`, `launcher/launcher_prompt_dialog.py`, `proxy/package.json`, `proxy/package-lock.json`, `README.md`, `docs/changelogs/README.md`, `docs/changelogs/v0.2.3.md`).
- Added comprehensive UI and theme audit tests in `tests/test_theme_and_model_rules_ui.py` and verified against existing navigation, tray, model rules, persistence, and quota display test suites under `QT_QPA_PLATFORM=offscreen`.
